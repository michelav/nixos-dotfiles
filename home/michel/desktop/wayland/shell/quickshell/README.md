# Quickshell desktop shell

This module installs a Quickshell configuration under
`$XDG_CONFIG_HOME/quickshell` when `userPrefs.desktopShell = "quickshell"`.
It provides one top bar per connected monitor, monitor-scoped Hyprland
workspaces, status widgets, a tray, and three popup panels.

## Organization

- `default.nix` selects the package, publishes the QML files through
  `xdg.configFile`, supplies executable paths, and defines
  `quickshell.service`.
- `theme.nix` generates `Theme.qml`. It is the bridge from Nix/Stylix values and
  Nix store executable paths into QML.
- `scripts.nix` builds small read-only helper programs for system load, network,
  Wi-Fi, brightness, and calendar data.
- `calendar.nix` configures the calendar data used by the agenda panel.
- `qml/shell.qml` is the entry point. It enables `QApplication`, tracks PipeWire
  audio objects, and creates one `Bar` for every `Quickshell.screens` entry.
- `qml/Bar.qml` defines bar dimensions, placement, widget ordering, and the open
  state of its popup panels.
- `qml/Widget.qml` is the shared status-pill component; `qml/Slider.qml` is the
  shared slider component.
- `qml/widgets/` contains the workspace, submap, media, clock, system usage,
  quick settings, language, battery, network, volume, and tray components.
- `qml/panels/` contains `ControlCenter`, `CalendarPanel`, and `SystemPanel`.

Static QML files are copied as-is. Do not edit the generated
`~/.config/quickshell/Theme.qml`; edit `theme.nix` and activate the Home Manager
configuration instead.

## Common tweaks

### Bar size, spacing, and placement

Edit `qml/Bar.qml`:

- `implicitHeight` controls the bar height and its reserved Hyprland zone.
- The `anchors` block places the bar at the top and stretches it across its
  assigned monitor.
- The main `RowLayout` controls widget order and spacing.
- Its left and right margins use `Theme.outerGap`, generated from Hyprland's
  `general.gaps_out`, so the bar content aligns with tiled windows. Change the
  source gap in `wayland/hyprland/default.nix` rather than adding a second value.

Shared pill height, horizontal padding, radius, and text size live in
`qml/Widget.qml`. Workspaces and the grouped Quick Settings block have their own
matching dimensions in `qml/widgets/Workspaces.qml` and
`qml/widgets/QuickSettings.qml`.

### Colors and fonts

The palette and font family names are generated by `theme.nix` from Stylix:

- Change `userPrefs.colorSchemeName` in `home/michel/default.nix` to select a
  different Base16 scheme.
- Change the Stylix `sansSerif` or `monospace` definitions in
  `modules/hm/userPrefs.nix` to replace the font families globally.
- Adjust the semantic color mapping in `theme.nix` when only Quickshell should
  interpret a Base16 color differently.
- Adjust `font.pixelSize` in `qml/Widget.qml` for shared bar text. Components
  with specialized text, such as workspaces and popup panels, define their own
  `font.pixelSize` locally.

`Theme.qml` exposes semantic names such as `bg`, `fg`, `moduleBg`,
`workspaceUrgent`, `warning`, `critical`, and `accent`. Prefer these properties
over hardcoded colors in components.

### Icons

Most symbols are Nerd Font glyphs embedded in widget text, so their size follows
the component's `font.pixelSize` and their availability depends on the configured
JetBrainsMono Nerd Font. The system tray uses image icons; change
`implicitSize` in `qml/widgets/Tray.qml` to resize them.

### Widgets and panels

To reorder or remove bar content, edit the `RowLayout` in `qml/Bar.qml`. Add new
static QML files to `qmlFiles` in `default.nix`, otherwise Home Manager will not
publish them into the active configuration.

Popup placement and visibility are owned by `Bar.qml`. The tray menu is separate:
each tray icon has a `QsMenuAnchor` in `qml/widgets/Tray.qml`, including its edge,
gravity, and on-screen adjustment behavior.

## Programs and generated helpers

`default.nix` injects absolute Nix store paths into `Theme.qml` for:

- `brightnessctl`, used for display brightness;
- `wpctl`, used for PipeWire volume and mute controls;
- `pavucontrol`, opened for detailed audio settings.

`scripts.nix` provides:

- `systemStatusScript` for CPU, memory, load, and temperature;
- `networkStatusScript` for the current NetworkManager connection;
- `wifiListScript` and `wifiConnectScript` for Wi-Fi selection;
- `brightnessStatusScript` for the current brightness percentage;
- `calendarAgendaScript` for the next 14 days from `khal`.

Keep executable references in `default.nix` or `scripts.nix` instead of relying
on the interactive shell's `PATH`; this keeps the configuration reproducible.

## Build, restart, and troubleshoot

Build before activation:

```console
nix build .#nixosConfigurations.vega.config.system.build.toplevel
```

Activate the host configuration when ready:

```console
sudo nixos-rebuild switch --flake .#vega
```

Quickshell normally watches QML files and reloads them, but changes to instance
pragmas such as `UseQApplication`, generated configuration, or service settings
require a full restart:

```console
systemctl --user restart quickshell.service
```

Inspect service state and recent logs with:

```console
systemctl --user status quickshell.service
journalctl --user -u quickshell.service -b -n 200
```

The deployed files are under `~/.config/quickshell`, but they are managed by Home
Manager. Make lasting changes in this repository, rebuild, and reactivate.
